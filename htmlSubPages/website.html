Description

The portfolio website is a personal project that developed to display my currently compeleted and in-progress projects, in addition to some information about myself. It originally started as a side project to improve my software development skills, and later developed into the primary place to display my projects.

Current iteration of the website


Challenges

Navigation bar (check if keep)

In the first iteration, the main challenges were getting the navigation bar to work, and making the website work on mobile browsers. The primary issue with the latter, was that it was specifically designed for my phone in particular. It broke with different website sizes, specifically for tablets and scaled computer browser windows.
The second iteration resolved the issue by foregoing the requirment entierly. Due to this, the CSS is much easier to maintain, and adding new content does not break the formatting. The navigation bar was not used due to changes in style preferences.

Content amount

The primary challenge with the second website, is the sheer amount of content that now needs to be put in, a result of 2 extra years of engineering work from when the website was first created.


What I learned

The major lesson I learned from this endevor was learning about the point at which the resources invested do not justify the resulting product. Making the original website compatible for mobile did not solve any problems, rather it introduced many new ones. Changing minor things would often cause the website to break its formatting competley. This in addition to manually adjusting the spacing values, lead to a massive waste of time on my end.
