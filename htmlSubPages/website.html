Description

The portfolio website is a personal project that developed to display my currently compeleted and in-progress projects, in addition to information about myself. It originally started as a side project to improve my software development skills, and later developed into the primary place to display my projects.

Current iteration of the website


Challenges

Consistency

The greatest challenge I have encounted in the website was the consistancy required to maintain its displayed information. It is by far, and for the time being continues to be my longest running project. My original intention was to keep it maintained for major updates on my projects, but that proved infeasable.

I have taken a more active role in the website once again, and now aim to keep it activly maintained, with constant updates upon complete each project, or if an update is required. This makes it significantly easier to keep the website maintained, with only completed projects requiring updates.


What I learned

The major lesson I learned from this endevor was learning about the point at which the resources invested do not justify the resulting product. The first iteration of the website was made compatible for mobile. This proved to be a mistake, as it introduced many problems for minor gains.
