ASL Hand Tracker

Python Blender C++ MediaPipe

Description

The American Sign Language (ASL) Hand-Tracker project was the final project of ENSC 482 (Introduction to Decision Making in Engineering). It is designed to track the user's hand, and determine the displayed letter or number. It is capiable of understanding each of the 26 letters of the English alpabet, as well as numbers 1-10. In addition, a real-time virtual representation of the hand is displayed in blender. Interestingly enough, the software is also somewhat capiable of tracking feet similar to fingers. It can be found as a repository on my GitHub.

Challenges

Axis system

The primary challenge of this project, was figuring out the axis system that the fingers could use. Since this axis system would need to rotate along the wrist, and ideally would be compatible with the thumb.

To account for this, I developed a system that works off a "basis frame." This basis frame is either the first frame captured, or a use selected frame. The rotations of the wrist are then found in relation to this frame. The 3D axis is developed relative to this rotation, with a palm normal vector, across (index knuckle to pinky knuckle) vector, and vertical (from wrist to middle finger knuckle). Since this axis is applied at the basis of the bone being rotated, this system additionally works for the thumb.

Tuning

Tuning was a unique challenge, primarily due to how similar a lot of symbols were. More problematic was that some letters required full hand movement. Since the virtual model was rooted in place, this was impossible. I ended up finding an alphabet that didn't require movement. In theory, this may be possible to impliement, but it would require a lot of work, as MediaPipe cannot easily track movement.

This made tuning more difficult, as many letters had only minor differences, tracking is difficult. In the time frame I was given, I did a decent job, as every letter was trackable. However, with more time, the tuning could be vastly improved.


What I learned

The 2 main things I learned from this, were Python and Blender. Since the MediaPipe and Blender portion ran on Python, I was required to learn Python properly. I had limited experience working with Python from a previous hackathon, where I made a chatbot using ChatGpt API to replicated modern slang. However, I only had limited work with the Python, as it was a 4 man team. This project really force me to properly learn Python in a practical setting.

In addition, I gained experience working with Blender, as the virtual recreation was done in Blender. I learned about rigging, bones, and scripting using Python. In addition, I had a practical application to apply my vector knowledge, using knowledge of normalization, and matricies to create the axis and rotational systems.
