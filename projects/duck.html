Ducks in a Row

Hackathon C# Unity GitHub

Description

In a group of 4, during the StormHacks hackathon, I helped in the creation of a puzzle game named Ducks in a Row. The game was developed in Unity and C# over the course of 24 hours, with GitHub used for version control. I primarily worked on the game mechanics and helped in the level design and development. Short gameplay of the first level



What I learned

The 2 main things I learned were Unity and C#. Since this was my first time creating a game, it was very interesting to learn about and experience the game development cycle, as well as learning the tools used to create games. In addition, this was the first major time I used GitHub, and I gained much needed exposure during the hackathon.
